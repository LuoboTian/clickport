# Clickport

Mac 文件操作工具：Finder 右键操作与设置管理。

**当前阶段：V1 开发。需求、交互设计与隔离技术探针已形成基础，共享模块、主应用及 Finder 扩展正在实现；尚未完成实机验收。**

## Review 顺序

1. [产品定义](docs/product.md)：用户、定位、命名。
2. [1.0 需求与验收](docs/requirements.md)：完整范围与行为契约。
3. [UI 设计](docs/ui/design.md)：菜单栏状态菜单、设置、右键与异常状态。
4. [交互 UI 设计稿](docs/ui/wireframes.html)：在浏览器打开；可切换设置栏目与右键上下文，操作均为模拟。
5. [架构提案](docs/architecture.md)：职责、权限与技术验证。
6. [测试与 CI 计划](docs/quality.md)：单测、集成、实机、发布关卡。
7. [Roadmap](docs/roadmap.md)：阶段与退出条件。
8. [协作规范](CONTRIBUTING.md)：分支、提交、PR 与变更管理。
9. [评审记录](docs/reviews/001-v1-review.md)：包含分阶段授权与开发范围。
