# UI 设计规格 · 待评审

配套 [交互设计稿](wireframes.html)。设计稿只执行页面内模拟交互，不执行系统或文件操作，不代表已实现，最终样式按原生 macOS 控件调整。

## 菜单栏图标与状态菜单 · FR-10

单色模板图标，跟随系统深浅色。点击展开简洁菜单：Finder 扩展状态、设置…、退出。扩展状态用文字表示，包括已启用、未启用或状态未知；设置入口承接修复与权限管理。不提供常用目录、目标选择及文件操作。图标可隐藏，重新运行应用打开设置，避免无入口状态。

## 设置窗口

### 视觉方向 · FR-11 / FR-12 / FR-13

2026-09-29 设计修订：采用 macOS 设置式双栏结构，结合移动端设置常见的分组列表。此为用户提出参考方向后的设计提案，仍待视觉评审，不构成开发准入批准。

- 左侧固定分类，右侧显示当前页标题和设置分组。分类使用小尺寸统一图标与文字，选中态采用系统强调色。
- 内容区使用浅灰背景、白色分组、细分隔线与克制圆角；材质效果集中在窗口边框和侧栏，正文保持清晰。深色模式采用对应语义色。
- 设置行左侧为标题与辅助说明，右侧为开关、当前值或操作按钮。普通选项立即生效；应用编辑与菜单布局保留明确的保存/应用行为。
- 使用“登录时启动”“显示菜单栏图标”等正向文案；关闭菜单栏图标前说明重新运行应用可打开设置。
- 通用页按“启动与入口”“扩展与权限”“配置与诊断”分组。权限显示文字状态与管理入口；导入、导出和日志使用按钮；重置独立呈现并二次确认。
- 桌面控件保持紧凑，支持键盘、可见焦点及 VoiceOver；状态不能仅靠颜色区分。系统字体、强调色和原生控件的具体外观随支持的系统版本调整。
- 下述尺寸是本项目设计建议，不是平台强制标准。仅调整布局与视觉，不新增设置能力。

参考：[Apple Human Interface Guidelines · Settings](https://developer.apple.com/design/human-interface-guidelines/settings)。


初始尺寸建议 960×680pt，最小 760×540pt。侧边栏约 180pt；原生系统字体，表单间距 16–24pt，点击区至少 28pt，支持键盘 Tab 和焦点可见。

导航：通用、打开方式、文件操作、新建文件、目录快捷入口、右键菜单、关于。

应用页使用列表与编辑 Sheet，参数/环境变量收进高级选项；新增与编辑明确保存/取消。模板页显示类型、模板来源与可用性。目录页显示真实位置与离线状态。通用页显示扩展、授权及启动设置。

菜单布局：可用项目、菜单树和上下文预览；预览切换空白/单文件/多选。修改是草稿，点击应用后生效；关闭有未保存更改时提示保留或放弃。JSON 导入错误显示具体节点，已生效菜单保持不变。

## Finder 菜单

默认四组：打开方式、新建文件、文件操作、常用目录。用户可平铺高频项。失配操作隐藏或禁用并提供合理说明；系统实际插入位置待验证。直接删除默认不出现。

## 首次使用与异常

首次打开设置，说明启用 Finder 扩展的必要性；目录访问和辅助功能在使用时再请求。新建后自动进入重命名需要额外能力时，拒绝权限仍须创建与定位成功。

覆盖：未启用扩展、主应用不可达、没有目标、目标已删除、无权限、模板丢失、应用卸载、卷离线、配置无效、部分成功。错误文案包含对象概述、原因和下一步，不直接展示堆栈。

直接删除确认：列出目标数量、可展开路径、不可恢复提示；取消为默认操作。批量操作只汇报实际成功的数量。

## 交互评审覆盖 · 2026-09-29

用户明确要求将 HTML 作为交互式设计稿，并展示全部设置模块及右键内容。本次仅包含文档内 HTML/CSS/JavaScript 设计模拟，不含应用实现、Xcode 工程或技术原型。

- Finder：单文件、文件夹、多文件、空白处四种上下文；四组子菜单；根据设置显示应用、模板、目录及文件操作。无选中对象时禁用依赖目标的操作，多选新建先选择目录，直接删除默认隐藏、启用与执行均确认。
- 设置：七类页面完整展示；开关、示例应用及目录的添加/编辑/移除/排序、模板来源、布局排序与应用、深浅色可操作。高级参数编辑仅为表单外观演示，不持久化；完整嵌套树编辑、配置导入导出、授权和更新流程使用说明弹窗。
- 菜单栏：仅扩展状态、设置和退出；撤销旧的目标选择与文件操作面板方案。
- 页面刷新恢复示例数据，不读取真实文件，不操作剪贴板，不请求系统权限，不联网。系统菜单位置、模板有效性和权限状态均非实机验证结果。

### 桌面右键 · FR-01 / FR-03 — FR-09

桌面属于 Finder 上下文，设计稿提供“桌面空白处”和“桌面上的文件”两种预览。空白处新建以桌面为目标；常用目录可直接打开；打开方式、隐藏选中项和 AirDrop 因没有选择目标而不可用；复制路径改为“复制桌面路径”，直接删除不显示。取消隐藏当前目录直接子项明确展示桌面范围且不递归。选中桌面文件时操作针对所选文件，新建位于桌面。

系统的新建文件夹、墙纸、叠放与排序菜单仅作位置示意。桌面上的扩展菜单是否可出现、授权边界及具体位置必须单独实机验证；交互稿不代表技术能力已验证。

## Mac 视觉与交互精修 · 2026-09-29

用户明确要求以 Mac 为唯一设计基准，授权继续修改 HTML 设计预览。设置采用约 42pt 的基础行高、190pt 侧栏、统一的 28pt 最小按钮高度与 13pt 正文字号；这是本项目预览尺寸，不是平台强制值。移除重复说明，保留权限、不可恢复操作和入口恢复提示。七个模块共享控件、分隔线、圆角、字体和线性图标规则。

桌面场景去除 Finder 侧栏，使用独立桌面背景和右侧文件图标。原位右键根据空白处或文件确定上下文。菜单支持悬停展开子菜单、移出菜单区域后 300ms 收起子菜单、点击外部收起及边界翻转；主菜单在移出时保留。窄预览区域空间不足时允许子菜单覆盖主菜单的一部分。

上述交互用于 HTML 演示，不新增产品能力。正式应用优先使用原生菜单并沿用系统行为，不将模拟延时和 HTML 定位方式作为实现要求。实际 Finder/桌面菜单支持情况仍需授权后的技术验证。

## 自定义快捷操作 · FR-03 / FR-09 · 2026-09-29

用户同意在菜单布局中增加快捷操作区。默认复制路径，支持从已有操作选取、排序、移除及留空，最多 5 项，推荐 1–3 项。预览提供复制路径、隐藏/取消隐藏选中项、AirDrop、新建纯文本和 Markdown；不开放脚本、Shell 或直接删除。与分组顺序共同应用，恢复默认也恢复复制路径快捷项。

快捷操作在扩展第一层显示，并以分隔线与四个分组区分；原分组入口保留。来源功能关闭时隐藏对应菜单项并保留配置；上下文不适用时灰显。单文件/目录/多选/目录空白/桌面空白分别显示“复制文件路径”“复制文件夹路径”“复制所选项路径”“复制当前文件夹路径”“复制桌面路径”。这修订了空白处禁用复制路径的旧规则，菜单栏不提供文件操作。

## 菜单栏精简 · 2026-09-29

用户同意取消独立文件操作面板，菜单栏只保留扩展状态、设置与退出。需求编号保留在文档用于追踪，从 HTML 产品界面中移除。本次仅变更需求与设计，未进入应用开发。

关于页增加 GitHub 项目仓库按钮；地址未确定时显示“地址待配置”，点击说明状态，不跳转猜测的地址。用户确认地址后再接入。登录启动默认关闭，与产品定义一致。

## 设置命名与职责 · 2026-09-29

用户同意统一栏目为通用、打开方式、文件操作、新建文件、目录快捷入口、右键菜单、关于。文件操作管理能力启停；右键菜单管理入口位置与排序。移除快捷项只移除第一层入口，分组入口保留。关闭能力则隐藏所有对应入口，快捷配置保留并提示来源关闭。

“文件夹访问权限”负责权限管理，与“目录快捷入口”分开。“恢复默认设置…”确认范围为通用选项、操作开关、菜单布局及自定义应用/目录/模板引用；不删除实际文件或应用、不撤销系统权限。右键菜单中的“恢复默认菜单…”仅恢复分组顺序及快捷操作。HTML 全局恢复会回到初始示例数据。

## 右键菜单设置页结构 · 2026-09-29

用户同意按“第一层快捷操作 → 菜单分组顺序 → 高级自定义 → 保存/放弃”排列。移除重复的可用项目区；高级自定义默认折叠，复杂编辑仍以示例说明。修改后提示“有未保存的更改”；保存同时更新快捷项与分组，放弃还原到上次保存，来源功能开关不受影响。无修改时按钮禁用。恢复默认菜单先修改草稿，再保存生效。

来源关闭的快捷项保留配置提示，并提供前往文件操作或新建文件的按钮；离开时可保留草稿，预览继续使用已保存配置。
