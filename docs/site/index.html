你可能想了解

网页演示会访问我的文件吗？

不会。设计稿使用示例数据，按钮模拟操作结果；刷新后恢复初始状态。网页演示不等于原生功能验收。

Mac 上需要开启什么权限？

原生应用需要启用 Finder 扩展，并按需授权操作目录。新建文件后定位文件，V1 不依赖辅助功能自动进入重命名。

现在能添加自己的脚本吗？

V1 支持配置应用、模板、目录及已有快捷操作。任意脚本、插件与快捷指令执行属于后续规划。
