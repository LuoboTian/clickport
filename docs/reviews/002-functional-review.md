## 优先建议讨论

1. 确认空白处“在当前目录打开终端/编辑器”的目标规则，避免只在已选中目录时可用。
2. 确认快捷操作可选择具体应用、常用目录和模板，还是首版仅包含固定动作。
3. 确认 Office/iWork 首次使用需要用户导入模板，或提供经过验证且可分发的内置模板；不得伪造空扩展名文件。
4. 现有范围含完整菜单树、五种语言、高级启动、多格式模板；可讨论发布顺序，但未经用户确认不删减范围。
