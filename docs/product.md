# 产品定义 · 待评审

## 命名

工作名 Clickport：Click 表示操作入口，port 表示通往文件、应用与目录的入口。备选 iRight 更直观，但容易被理解成仅有右键能力。备选名称为 Clicklane。名称属于创意候选，尚未核验商标、域名或商店重名，不作为注册可用性结论。

确认前以 Clickport 建立独立目录；品牌名称与持久化标识分离，正式 Bundle ID 在开发前确定。

## 用户与价值

面向经常在 Finder、编辑器和终端之间处理文件的 Mac 用户。减少找应用、重复定位目录和新建文件的步骤。产品价值假设：通过上下文正确、配置清楚和失败可解释，使常用文件操作更顺手；尚未验证市场或付费意愿。

## 形态

- Finder 右键：针对当前目录或选中文件直接操作。
- 菜单栏图标：单击显示扩展状态、设置和退出；不提供文件操作。
- 设置窗口：维护应用、模板、目录、动作和菜单布局。

默认显示菜单栏图标、关闭登录启动；主应用不依赖服务端。允许隐藏图标，但设置可由再次启动应用打开。

## 1.0 边界

包含应用打开、路径复制、直接删除、隐藏属性、新建模板文件、AirDrop、常用目录、菜单定制、授权和配置管理。

不包含宠物、AI、全局右键接管、复制/移动工作流、批量重命名、通用撤销、剪贴板历史、OCR、压缩、窗口管理或账户同步。

成功标准：核心场景不误操作对象；失败有可理解反馈；在一周体验中验证至少两个自然使用的高频动作。该体验目标不是现有结果。
