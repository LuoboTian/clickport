# 架构 · V1 实现中

SwiftUI 设置与菜单栏状态菜单 + AppKit 系统交互 + Finder Sync 扩展。工程已开始实现；尚未验证全部系统接口及真实 Finder 流程。

职责：扩展只构建菜单与提交明确目标；主应用执行动作、管理配置和授权。领域层负责菜单校验、目标解析、文件命名和结果汇总；系统适配层封装文件系统、应用启动、剪贴板、共享与权限。

主应用和扩展通过 App Group 共享配置及有时限的动作请求文件；消费后删除请求，逐项检查结构与当前操作配置。消息需校验动作标识、目标和来源，不把任意命令字符串作为协议。避免权限较弱进程请求执行超出用户操作的动作。

主应用和扩展均启用 App Sandbox。主应用以用户选择目录生成的安全作用域书签访问用户目录；授权记录独立保存在主应用容器，文件权限为 0600。执行时获取作用域，完成或取消后释放；设置支持撤销记录。执行范围以具体目标为准。菜单不扫描磁盘内容。配置版本化，迁移失败保留原文件。导出配置不带凭证及可复用授权。环境变量可能含秘密，不写诊断日志。

目录按用户确认的结构组织：Apps/Clickport、Extensions/FinderExtension、Packages/ClickportCore、Tests、Scripts、packaging/dmg、docs 和 experiments。

持续验收：扩展签名/App Group/激活；空白与选中项目标；桌面/外置卷/云盘；应用参数与新实例；有效 Office/iWork 模板；隐藏菜单栏图标后的设置恢复；最低系统与发行渠道。隔离技术验证与 V1 开发已获授权，真实权限及发行验收仍逐项记录。

发行方向为 DMG + Homebrew；正式发布地址和更新机制仍待落实。当前没有引入第三方源码；未来复用必须满足授权并保留必要声明。

## 后续扩展约束
