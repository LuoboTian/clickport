# Roadmap

2026-09-29：用户确认将扩展方向纳入后续路线，本期聚焦第一版规划。后续阶段是候选顺序，不承诺版本号或工期，不构成实现授权。

## 第一版 · 当前规划

| 阶段 | 交付 | 退出条件 | 状态 |
| --- | --- | --- | --- |
| S0 产品与澄清 | 名称、用户、范围、菜单栏范围 | 产品负责人确认 | 待评审 |
| S1 需求与设计评审 | FR 清单、UI 稿、验收矩阵 | 需求/UI 问题关闭并明确批准 | 评审中 |
| S2 技术评审 | ADR、权限/扩展实验计划、测试与 CI 方案 | 批准技术验证范围，验证后批准开发 | 待 S1 |
| S3 开发 | 四类能力、状态菜单与设置；小 PR | 每项关联需求、评审及自动检查通过 | 未开始 |
| S4 测试与验收 | 自动化、签名实机、缺陷闭环 | 所有 1.0 条目通过或经明确批准调整范围 | 未开始 |
| S5 发布 | 签名包、版本说明、限制与回滚 | 发布评审批准 | 未开始 |

批准开发后的建议顺序：扩展与目标/权限 → 应用与新建/路径 → 隐藏/删除/共享/目录 → 状态菜单和菜单布局 → 配置/语言/发行配套。分批交付不减少 1.0 范围。

每项需求状态：草稿 → 已澄清 → 已批准 → 开发中 → 待测试 → 已验收。变更必须说明范围、UI、测试和进度影响，并重新批准受影响部分。

## 第一版范围与待定项

完整范围以 [需求与验收](requirements.md) FR-01–FR-13 为准，P0 与 P1 均保留，不因分批交付而删减。

| 工作包 | 内容 | 关联需求 |
| --- | --- | --- |
| 文件与应用操作 | 应用打开及高级启动、路径复制、隐藏属性、可选直接删除、AirDrop | FR-01–06 |
| 新建与目录入口 | 文件模板、导入模板、常用目录管理 | FR-07–08 |
| 菜单配置 | 第一层快捷操作、分组排序、保存/放弃、配置校验；高级菜单编辑范围待明确 | FR-09 |
| 设置与可用性 | 简洁状态菜单、按需授权、设置恢复、配置与脱敏日志 | FR-10–12 |
| 发布配套 | 深浅色、键盘与 VoiceOver、多语言、版本/更新/反馈/GitHub 入口、安装升级验证 | FR-13 |

本期用户自定义限于配置已有能力：添加应用、模板和目录，以及选择/排列菜单入口。不开放任意脚本、插件或快捷指令执行。

开发前继续关闭 [功能评审](reviews/002-functional-review.md) 的问题：空白处打开应用的目标规则、具体应用/目录/模板能否固定为快捷项、Office/iWork 模板来源、退出后的扩展行为、配置导出边界。高级菜单编辑此前只提出过延期建议，尚未确认删减，需单独定范围。最低系统、芯片、语言与发行渠道也需评审确定。

## 后续扩展路线 · 不计入第一版验收

| 阶段 | 候选内容 | 进入条件与验收重点 |
| --- | --- | --- |
| E1 官方新增动作 | 批量重命名、压缩、图片格式转换 | V1 核心场景验收后，按实际需求逐项立项；预览变更、冲突处理、进度、取消与部分失败规则明确 |
| E2 用户工作流 | 接入 macOS 快捷指令，用户选择指令并将选中文件传入 | 先批准技术验证，确认传参、多选、授权、取消/超时和结果反馈，再评审配置入口 |
| E3 高级用户扩展 | 脚本或插件机制 | 有明确需求后单独评审执行权限、来源信任、参数边界、超时、诊断、禁用及配置分享；不默认开放任意命令 |
| 独立候选 | AI 文件处理 | 单独确认使用场景、本地或云端处理、上传授权、费用及结果确认；不作为 V1 依赖，也不预先新增设置栏目 |
| 其他候选 | 复制/移动、可撤销操作 | 单独定义目标、重名覆盖、跨卷行为和撤销能力边界后再排期 |

## 架构预留 · 仅设计约束

动作与菜单展示解耦。动作定义预留稳定标识、名称/图标、适用对象与多选能力、所需权限及配置、执行入口、进度/取消和结果格式。第一版只实现当前需求实际需要的部分，不提前搭建插件平台。

新增动作优先复用现有分组和快捷操作配置。菜单层级编辑只改变入口结构，不等于执行脚本或增加新能力。每项后续能力需补充独立需求编号、设计与验收标准，并获范围授权后开始实现。
