## 上下文契约

右键目标捕获在触发菜单时；执行前再次确认目标存在、类型和权限。新建：空白处使用当前目录，选中目录在目录内创建，选中文件在父目录创建；多选新建只允许用户明确指定一个目标目录，禁止默默选第一项。

菜单栏仅提供状态与应用管理入口。文件操作统一在 Finder / 桌面右键中执行，菜单栏不读取、保留或操作文件目标。

## 非功能与兼容

原始 URL 贯穿执行，禁止随意二次百分号解码。文件操作不阻塞菜单展示；超过一秒显示处理中状态；性能指标在技术原型后定量确认。

最低系统建议 macOS 15.0+（待实机验证），首验 Apple Silicon；Intel 在对应环境通过前不标记兼容。覆盖本地目录和桌面；外置盘、网络卷及云盘分别验证菜单出现、访问授权、只读、离线及占位文件，不承诺未测场景。

文件操作默认无网络；主动检查更新可联网。目录授权不等于整个磁盘读取授权。无账户、无内容上传、无后台文件扫描。

快捷操作与菜单布局共用草稿及应用机制；原分组保留入口。来源功能关闭时快捷项隐藏并保留配置，设置中提示“来源功能已关闭”；上下文不适用时快捷项灰显，不改变操作目标。空白处复制路径规则仅用于 Finder / 桌面，菜单栏不提供文件操作。

设置栏目统一为通用、打开方式、文件操作、新建文件、目录快捷入口、右键菜单、关于。恢复默认设置需确认：恢复通用选项、操作开关与菜单配置，清除自定义应用/目录/模板引用；不删除实际文件或应用、不撤销系统权限。恢复默认菜单仅影响分组与快捷操作。
